# Interactive-Resources Code Review — 2026-04-23

Four-agent parallel audit: security, performance, code quality, modernization.
Stack: Next.js + React 19, `output: 'export'` (static export for Capacitor iOS), no Tailwind (inline styles via `lib/theme.js`), no shadcn (mostly).

> **Architectural constraint:** `next.config.mjs` forces `output: 'export'`. This rules out API routes, Server Actions, Cache Components, middleware, ISR, and most Next.js 16 caching features. Recommendations respect this.

### The architectural question

Because this site is statically exported (for Capacitor iOS), you **cannot** add Next.js API routes for validation. The options:

- **Option A — Strict Supabase RLS.** Write RLS policies that validate the token inside Postgres: use `auth.jwt()` or `get_student_by_token()` as an RLS function returning the allowed `student_id`. Every insert becomes a server-verified operation. Cleanest architectural fit with static export.
- **Option B — Proxy via grades-dashboard.** Host the auth-sensitive writes as routes on `grades.musictechstudio.co.uk` (which already has `validateStudentToken()`) and have interactive-resources fetch them with CORS. Keeps one auth implementation.
- **Option C — Drop `output: 'export'`.** If Capacitor iOS is truly years away, you could drop static export now and re-add it when needed. Unlocks API routes and Server Actions. Risky if iOS remains on the roadmap.

**Recommendation:** Option A. It's the correct long-term answer, fits static export, and teaches you a real Postgres/RLS pattern you'll reuse.

**Clean:** No committed secrets, no `Access-Control-Allow-Origin: '*'`, no raw SQL injection, no service-role key usage.

## Tier 2 — High-ROI wins

1. **Resource registry ships every component to every page** — `app/[resourceId]/ResourcePageClient.js:13-55` eagerly static-imports 35+ resource components. Each URL only renders one. Fix: `next/dynamic` keyed off `resourceId`. *(medium effort, huge bundle win)*

2. **SplashCursor WebGL fluid sim on every mobile visit** — `components/SplashCursor.jsx` (1070 lines) mounted unconditionally in `app/page.js`. Biggest mobile main-thread/GPU cost. Fix: gate behind `matchMedia('(pointer: fine)')` + `prefers-reduced-motion`, lazy via `dynamic({ ssr: false })`. *(trivial)*

3. **Three.js + ShapeBlur in landing-page main bundle** — ShapeBlur is decorative at 0.12 opacity. `dynamic({ ssr: false })` or remove. *(trivial)*

4. **`app/page.js` is `'use client'` for a mostly-static hub** — hydrates 359-line tree with 5 heavy effects on mount. Convert to Server Component shell + client islands. *(medium)*

5. **`TopicBook.jsx` generates canvas covers on main thread per mount** (`canvas.toDataURL`) — N topics = N sync encodes. Fix: pre-generate at build time (script → `/public/topic-covers/*.png`), reference as static URLs. *(medium)*

6. **Hero MP4s unoptimized** — 12+ files loaded as raw `<video>` with no `preload="metadata"` or poster. Biggest payload win especially for eventual Capacitor iOS bundle. *(medium)*

7. **15 god-files in `components/resources/`** — peaking at `RevealExplorer.jsx` (2,723), `EQFilterBridge.jsx` (1,916), `DelayFlashcards.jsx` (1,803). Each inlines the same `DESIGN_TOKENS_CSS` block. Fix: extract shared tokens module first (biggest single win); split god-files opportunistically. *(medium-large)*

8. **6 near-duplicate `*ImageExplorer` + `*Assessment` pairs** — likely purely config wrappers. Audit whether they can collapse into the generic `ImageExplorer.jsx` base driven by `lib/image-explorer-configs/`. *(medium)*

## Tier 3 — Modernization (what's available under static export)

- **Add PostHog** — biggest blind spot in your analytics stack. Easter revision happens here and is currently unmeasurable. Mirror grades-dashboard's client-side provider. *(trivial)*
- **Add PWA manifest + service worker** — highly relevant with Capacitor iOS planned and students on poor school Wi-Fi. `next-pwa` or hand-rolled. Cache hero MP4s, questions JSON, lesson text for offline. *(medium)*
- **`useOptimistic` for quiz answer submission** — `saveQuizResponse` is fire-and-forget; optimistic UI eliminates perceived latency on slow networks. *(trivial)*
- **`useActionState` on AuthGate form** — cleaner pending/error states. *(trivial)*
- **Route-level `error.js` + `not-found.js`** — missing everywhere. *(trivial)*
- **`<Suspense>` boundaries** — wrap `LiquidHero`, `SplashCursor`, `ShapeBlur`, `TopicBookShelf` so they don't block first paint. *(trivial)*
- **`next/image` on static images** — even with `unoptimized: true`, gives lazy-load + dimension reservation. *(trivial)*

**Not applicable** (static export blocks them): Server Actions, Cache Components, `'use cache'`, async Server Components fetching at request time, streaming, `loading.js` at runtime.

## Tier 4 — Code hygiene

- **`app/prototype/` has 5 unlinked experiment routes** (`colour-coded`, `levels`, `retrieval`, `spell-demos`, 842-line `page.js`) shipping in production bundles. Gate behind `NODE_ENV !== 'production'` or delete.
- **Root-level SQL clutter** — `supabase-essay-responses.sql`, `supabase-quiz-responses.sql`, `-v2.sql`, `-read-then-quiz.sql`, `shaping-revision-quiz.md`, `demos/option-a-spine-layout.html`. Move to `supabase/migrations/` + `docs/plans/`.
- **Tailwind + inline styles mixed** — Tailwind installed, 10/44 resource components use `className=`. Pick one. If inline is canonical, remove Tailwind from deps.
- **Empty `components/shared/` directory** — delete or populate.
- **Half-implemented shadcn in `components/ui/`** (`alert`, `button`, `card`, `progress`, `slider`, `tabs`, `Popover`) — verify actually used; if not, dead weight.
- **`lib/resources/index.js:79`** — stale commented-out registry entry (`'adsr-interactive'`). Delete.
- **`.js` vs `.jsx` inconsistent** — `LiquidHero.js`, `ProgressDashboard.js` render JSX but use `.js` extension.
- **Landing-page `setTimeout(..., 100)` for `isLoaded`** — delays LCP. Use CSS `@starting-style` instead.
- **`lib/learn/confidence-persistence.js` `.select('*')` after insert** — narrow to `.select('id')`.

**Clean:** No TODO/FIXME comments anywhere. Registry integrity clean (41/41 entries wired). `next/font` used correctly.
